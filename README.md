# AI-Powered Movie Recommender

A **Movie Recommendation System** built using the **MovieLens dataset**, leveraging **Collaborative Filtering** techniques such as **K-Nearest Neighbors (KNN)** and **Singular Value Decomposition (SVD)**.  
This project demonstrates a personalized recommendation model capable of suggesting movies based on user preferences and interaction data.

---

## **Overview**

This project implements an intelligent **Movie Recommendation System** using machine learning techniques.  
It uses **Collaborative Filtering** to analyze patterns in user ratings and interactions, providing personalized movie suggestions.  
The system highlights how **machine learning** can enhance recommendation engines through similarity detection and dimensionality reduction.

---

## **Features**

- **Collaborative Filtering:** Recommends movies based on user-item similarity.  
- **KNN-based Recommendations:** Finds similar users or movies to make predictions.  
- **SVD Implementation:** Applies matrix factorization to reduce dimensionality and improve accuracy.  
- **Scalable Design:** Capable of handling large datasets with performance optimizations.  
- **Project Report:** Includes methodology, evaluation metrics, and results analysis.

---

## **Dataset**

The dataset used in this project is sourced from the **[MovieLens Dataset](https://grouplens.org/datasets/movielens/)**.  
It contains user ratings, movie information, and metadata used to train and test the recommender model.

---

## **Techniques Used**

- Collaborative Filtering  
- User-User Similarity  
- Item-Item Similarity  
- K-Nearest Neighbors (KNN)  
- Singular Value Decomposition (SVD)
